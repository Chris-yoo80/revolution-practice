# 회전체 연습 앱 설계 (중1-2 도형 > 회전체)

작성일: 2026-11-12

## 1. 목적과 범위

중학교 1학년 2학기 '회전체' 단원 학생이 평면도형을 회전축 둘레로 한 바퀴 돌렸을 때 어떤 입체가 되는지 스스로 탐구하고, 자동 생성 문제로 반복 연습하는 웹앱.

- 사용자: 학생 개인. 주 기기는 갤럭시탭 등 안드로이드 태블릿(크롬), PC 브라우저도 지원. 로그인·서버 없음.
- 배포 형태: PWA(설치형 웹앱). 크롬에서 링크를 열고 '앱 설치' → 홈 화면 아이콘, 전체 화면 실행, 오프라인 동작.
- 다루는 내용
  - 기본 회전체: 직사각형→원기둥, 직각삼각형→원뿔, 사다리꼴→원뿔대, 반원→구
  - 복합·응용 도형: 여러 도형을 붙인 모양, 축에서 떨어진 도형(가운데가 빈 회전체), 축이 도형을 가로지르는 경우
  - 회전체의 단면: 회전축을 포함하는 평면 / 회전축에 수직인 평면
  - 역방향: 회전체를 보고 원래 평면도형과 축 찾기
- 범위 밖: 겉넓이·부피 계산, 전개도, 교사용 관리 기능, 학습 기록 서버 저장, APK·플레이스토어 배포

## 2. 기술 스택

- Vite + TypeScript + Three.js (정적 빌드)
- `polygon-clipping`: 다각형 합집합 연산
- `vite-plugin-pwa`: 웹 앱 매니페스트 + 서비스 워커 생성
- Vitest: `geometry/`, `quiz/` 단위 테스트

## 2.1 PWA·태블릿 대응

- 매니페스트: 이름 "회전체 연습", `display: standalone`, `orientation: any`, 아이콘 192/512px(+maskable), 테마 색.
- 서비스 워커: 빌드 산출물 전체(JS·CSS·HTML·아이콘·폰트) 사전 캐시 → 첫 실행 후 오프라인 동작.
  새 버전이 배포되면 다음 실행 시 자동 갱신(`registerType: autoUpdate`).
- 호스팅: HTTPS 정적 호스팅이 필요(PWA 설치 조건). GitHub 저장소 + GitHub Actions → GitHub Pages로 배포.
  `vite.config`의 `base`를 저장소 경로에 맞춘다. 원격 저장소 생성·배포는 사용자 확인 후 진행.
- 터치: 버튼·꼭짓점 핸들 터치 영역 최소 48px. 캔버스 영역은 `touch-action: none`으로 브라우저 스크롤·확대를 막고
  앱이 직접 드래그·핀치를 처리. 그 외 영역은 페이지 확대 비활성(`maximum-scale=1`).
- 기준 해상도: 갤럭시탭 S 시리즈 가로 1280×800 CSS px 이상, 세로 화면도 지원.
- 3D 성능: 기기 픽셀 비율을 최대 2로 제한, 회전체 메시 분할 수 64로 시작해 60fps 미달 시 낮춘다.

## 3. 핵심 기하 모델

모든 기능은 **반쪽 단면(half-profile)** 하나로 통일한다.

1. 입력: 2D 다각형 목록(복합 도형은 여러 개) + 회전축(세로축 x=c 또는 가로축 y=c).
   곡선(반원·원)은 64개 이상의 꼭짓점을 가진 다각형으로 근사한다.
2. 축 기준 좌표 변환: 각 점을 (t = 축 방향 위치, s = 축까지의 부호 있는 거리)로 바꾼다.
3. 접기: s < 0 인 부분을 s → −s 로 뒤집고, 원래 s ≥ 0 부분과 합집합한다.
   결과 = 반쪽 단면 H (s ≥ 0 영역의 다각형 집합, 구멍 허용).
4. 3D 렌더링: H 경계의 각 변 중 축 위(s = 0)에 놓인 변을 제외한 변을 축 둘레로 회전시켜 겉면을 만든다.
   회전 각도 θ(0°~360°)를 매개변수로 받아 애니메이션에 사용한다.
5. 축을 포함하는 평면으로 자른 단면 = H ∪ mirror(H) (항상 선대칭 도형).
6. 축에 수직인 평면(t = t₀)으로 자른 단면 = H와 직선 t = t₀의 교집합 구간 [a, b]들을
   반지름 a~b 의 원(a = 0) 또는 고리(a > 0)로 그린 것.
7. 판별(classify): H가 하나의 다각형이고 축 위 변을 가질 때
   - 직사각형 → 원기둥, 직각삼각형(직각변 하나가 축 위) → 원뿔,
     축에 수직인 두 변을 가진 사다리꼴 → 원뿔대, 반원 근사 → 구
   - 그 외 → 구성 요소 나열(예: "원기둥 + 원뿔") 또는 "회전체"
   - H에 축과 닿지 않는 부분이 있으면 "가운데가 빈 회전체"를 덧붙인다.
8. 동일성 비교(equality): 두 회전체는 반쪽 단면이 같으면 같다.
   축 방향 평행이동·정규화(t 최솟값 0) 후 두 H를 같은 64×64 격자에 스캔라인으로 찍어, 안/밖이 다른 표본이
   어느 한쪽 안쪽 표본 수의 1% 이하이면 같다고 본다. (polygon-clipping xor는 원 근사 다각형에서 예외가 나서 쓰지 않는다.)
   축 방향 뒤집기(t → −t)는 다른 회전체로 취급하지 않는다(3D에서 돌려보면 같으므로).

## 4. 화면 구성

### 4.1 홈
[탐구하기] [문제 풀기] 두 버튼.

### 4.2 탐구 모드
가로 화면: 좌 2D / 우 3D. 세로 화면: 위 2D / 아래 3D.

**2D 작업판 (모눈 캔버스)**
- 프리셋: 직사각형, 직각삼각형, 사다리꼴, 반원, 원, 복합 도형 3종(원기둥+원뿔 모양, 축에서 떨어진 직사각형, 계단 모양)
- 직접 그리기: 모눈 교점을 탭해 점 추가, 첫 점을 다시 탭하면 닫힘. 꼭짓점 드래그로 수정, [지우기]로 초기화.
  자기 교차 다각형은 닫기를 거부하고 안내 문구를 띄운다.
- 회전축: 세로/가로 토글, 드래그로 위치 이동(모눈 단위 스냅).
- 접힌 반쪽 단면을 옅은 색으로 겹쳐 표시.

**3D 보기**
- 회전 슬라이더(0°~360°)와 ▶ 재생 버튼: 도형이 축 둘레로 돌며 지나간 자리가 면으로 쌓인다.
- 터치/마우스 드래그로 시점 회전, 핀치/휠로 확대.
- [단면 보기]: 축 포함 / 축에 수직 선택, 슬라이더로 자르는 위치(축 포함: 회전각, 수직: t₀) 이동.
  자르는 평면을 반투명으로 표시하고, 단면 모양을 색칠해 별도 미니 패널에 2D로 크게 보여준다.
- 이름표: 판별 결과 표시.

### 4.3 문제 모드
- 시작 화면: 유형(전체/A/B/C), 난이도(기본/응용/심화) 선택. 한 세트 10문제.
- 문제 화면: 상단 문제 그림, 하단 보기 4개(2×2).
- 정답: 짧은 피드백 후 다음 문제.
- 오답: 해설 패널 — 문제 도형의 회전 애니메이션 + 학생이 고른 보기의 오답 유형 설명 한 줄 → [다음].
- 결과 화면: 점수, 유형별 정답률, 최고 기록(localStorage).

## 5. 문제 유형

| 유형 | 문제 | 보기 |
|---|---|---|
| A | 평면도형 + 축 | 회전체 3D 그림 4개 |
| B (역방향) | 회전체 3D 그림 | 평면도형 + 축 그림 4개 |
| C | 회전체 + 자르는 평면 | 단면 2D 그림 4개 |

**도형 풀**
- 기본: 축에 한 변이 붙은 직사각형, 직각삼각형, 사다리꼴, 반원. 크기는 모눈 2~6칸에서 무작위.
- 응용: 기본 도형 2~3개를 변으로 붙인 복합 도형, 축에서 1~2칸 떨어진 도형, 축이 가로지르는 도형.
- 심화: 기울어진 변이 있는 도형 — 양 다리가 기운 사다리꼴(축에서 떨어짐), 꼭짓점만 축에 닿은 평행사변형, 사다리꼴의 긴/짧은 밑변을 축으로 한 경우, 축이 기운 사다리꼴을 가로지르는 경우, 어느 변도 축에 붙지 않은 삼각형.

## 6. 오답 생성 규칙

각 규칙은 (문제 도형, 축) → 오답 후보와 해설 문구를 반환한다.

1. 반대쪽 축: 도형의 다른 변(또는 반대편 변)을 축으로 삼은 결과. — "다른 변을 축으로 돌린 모양이에요."
2. 빈 공간 메우기: 축에서 떨어진 도형인데 축까지 채운 결과. — "도형과 축 사이가 떨어져 있으면 가운데가 비어요."
3. 빈 공간 누락: 축에 붙은 도형인데 가운데를 비운 결과. — "도형이 축에 붙어 있으면 가운데가 채워져요."
4. 기둥 착각: 회전 대신 앞으로 밀어낸 각기둥(유형 A 3D 보기 전용). — "돌린 게 아니라 밀어낸 모양이에요."
5. 도형 변형: 축 방향 뒤집기가 아닌 변형(예: 직각삼각형의 빗변 방향 반전), 복합 도형 일부 조각 누락. — "원래 도형과 모양이 달라요."
6. 단면 혼동(유형 C): 축 포함 단면 ↔ 수직 단면 교체, 거울상 없이 반쪽만, 고리 대신 꽉 찬 원. — 각 상황별 문구.

**검증**: 정답과 모든 후보를 반쪽 단면으로 바꿔 `equality`로 비교한다. 정답과 같거나 서로 같은 후보는 버린다.
유형 C는 핵심 오답(가운데 빈/채움 혼동, 다른 높이, 반쪽만)을 먼저 뽑아 모양만 보고 맞히지 못하게 한다.
(규칙 4의 각기둥은 회전체가 아니므로 비교 없이 항상 다른 보기로 인정하고, 한 문제에 최대 1개만 쓴다.
유형 B의 보기는 '도형+축'에서 만든 반쪽 단면끼리, 유형 C의 보기는 2D 단면 다각형끼리 같은 대칭차 기준으로 비교한다.)
후보가 3개 미만이면 무작위 도형으로 채우고, 그래도 부족하면 문제를 다시 생성한다(최대 10회).
보기 순서는 무작위로 섞는다.

## 8. 오류 처리

- WebGL 미지원 브라우저: "이 기기에서는 3D를 표시할 수 없어요" 안내.
- 그리기 중 점이 3개 미만이거나 자기 교차: 닫기 거부 + 안내.
- 축이 도형과 전혀 관계없이 멀리 있어도 정상 처리(가운데가 빈 회전체).
- 넓이 0인 도형(일직선): 회전 불가 안내.

## 9. 테스트

- `geometry/` 단위 테스트
  - 기본 4종 판별 (직사각형/직각삼각형/사다리꼴/반원 → 이름)
  - 축에서 떨어진 직사각형 → 구멍 있는 반쪽 단면, "가운데가 빈"
  - 축이 가로지르는 직사각형 → 접힌 결과가 더 큰 쪽과 같음
  - 수직 단면: 원기둥 → 원 1개, 속 빈 원기둥 → 고리 1개
  - 축 포함 단면: 원뿔 → 이등변삼각형(선대칭)
  - equality: 같은 도형의 평행이동은 같음, 다른 축은 다름
- `quiz/` 단위 테스트
  - 유형·난이도별 150회(시드 고정) 생성 시 항상 보기 4개, 정답 1개, 보기 간 중복 없음
- 화면: 개발 서버에서 탐구·문제 모드를 직접 실행해 확인(1280×800 가로, 800×1280 세로 뷰포트).
- PWA: 프로덕션 빌드를 로컬 미리보기로 띄워 매니페스트·서비스 워커 등록 확인(Lighthouse PWA 설치 가능 항목),
  네트워크 차단 상태에서 새로고침해 오프라인 동작 확인. 실제 갤럭시탭 설치 확인은 배포 후 사용자가 수행.
